## 📞 Troubleshooting

### Landing page shows old design?
```bash
# Clear cache and restart
Ctrl+Shift+Del  # Clear cache
Ctrl+F5         # Hard refresh
python app.py   # Restart server
```

### Toggles not working?
```
1. Open DevTools (F12)
2. Check Console for errors
3. Verify JavaScript loaded
4. Check Network tab
```

### Page looks cut off on mobile?
```
1. Test with actual device or DevTools
2. Check viewport meta tag
3. Verify 768px breakpoint
4. Test in browser inspector
```
