## 📞 Support

### If Something Goes Wrong

1. **Check browser console** (F12 → Console)
2. **Check Flask terminal output** (error messages)
3. **Check documentation files** (for solutions)
4. **Try clearing cache** (Ctrl+Shift+Del)
5. **Restart Flask server** (Ctrl+C, then `python app.py`)

### Common Solutions

```
Landing page shows old design?
→ Clear cache (Ctrl+Shift+Del) + restart server

Toggles don't work?
→ Check console (F12) for JavaScript errors

Page looks cut off on mobile?
→ Check viewport meta tag, verify 768px breakpoint

Form submission fails?
→ Check browser console for fetch errors
```
